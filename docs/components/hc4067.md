# 74HC4067 analog multiplexer

Pinout image: [HC4067 pinout](assets/hc4067-pinout.png)

## Role in MCC Pro

Multiple HC4067 muxes share the same ESP8266 select lines:

- `S0` -> GPIO13
- `S1` -> GPIO12
- `S2` -> GPIO14
- `S3` -> GPIO16

The selected channel is `slot0 & 0x0F`, so C01 maps to channel 0 and C16 maps to channel 15.

## Current mux roles

| Board ref | Enable path | Role |
| --- | --- | --- |
| U10 | IC25/PCF8574 P0 LOW | Internal TC1047 temperature mux to ESP8266 A0 |
| U10E | IC25/PCF8574 P1 LOW | External temperature mux to ESP8266 A0 |
| U34 | IC25/PCF8574 P2 LOW | Shunt mux for internal INA219 |
| U3 | IC25/PCF8574 P3 LOW | External INA219 channel path |
| U2 | IC25/PCF8574 P4 LOW | Internal BAT+ mux for internal INA219 |

The internal INA219 path requires U2 and U34 enabled together on the same selected channel with PCF8574 mask `0xEB`.

## Quirks and safety notes

- U2 and U3 are not raw ADC paths; they route selected voltage/current paths to INA219 devices.
- U34 is not a standalone A0 diagnostic mux in the current model. It selects shunts for internal INA219 current measurement.
- All HC4067 enable lines are active-low through IC25/PCF8574, so helper code writes full PCF8574 byte masks and returns to idle `0xFF`.
- Do not mix arbitrary PCF8574 read-modify-write behavior with helper full-byte masks.
