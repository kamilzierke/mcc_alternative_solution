# PCA9685 16-channel PWM controller

Source datasheet: [NXP PCA9685 PWM controller](../datasheets/nxp-pca9685-16-channel-pwm-controller.pdf)

## Role in MCC Pro

The PCA9685 is identified as a 16-channel 12-bit I2C PWM controller candidate. The current helper contains experimental C16/Q34 test writes that assume:

- I2C address: `0x4F`
- Channel: LED15
- Board path: U36 LED15 -> R226 -> Q34 gate, based on the schematic fragment

This is not yet safe as a general output controller because `0x4F` is also used by the current internal INA219 path. Treat the PCA9685 role as unresolved until hardware probing confirms which device responds on the bus and under which mux/state conditions.

## Pinout

Pinout image: [PCA9685 pinout](assets/pca9685-pinout.png)

| Pin/group | Function |
| --- | --- |
| A0..A5 | Hardware address inputs |
| SDA, SCL | I2C bus |
| LED0..LED15 | PWM outputs |
| OE | Active-low global output enable |
| EXTCLK | Optional external clock input; ground if unused |
| VDD | Logic supply, 2.3 V to 5.5 V |
| VSS | Ground |

## Addressing

The regular PCA9685 address format is `1 A5 A4 A3 A2 A1 A0`. The datasheet also defines all-call, sub-call and software-reset addresses. Address pins do not include internal pull-ups, so the board strap must be traced or measured.

## Registers Used by Helper

| Register | Name | Current helper use |
| --- | --- | --- |
| `0x00` | MODE1 | Written as `0x20` for auto-increment enabled and sleep cleared |
| `0x06 + 4*n` | LEDn_ON_L | Channel PWM block base |
| `LEDn_ON_H bit 4` | Full ON | Used for 100 percent output |
| `LEDn_OFF_H bit 4` | Full OFF | Used for OFF output |
| `LEDn_OFF_L/H` | PWM off count | Used for duty-cycle tests |
| `0xFA..0xFD` | ALL_LED registers | Useful for future all-output safe-off routines |
| `0xFE` | PRE_SCALE | Not written by current helper |

## Current Test Actions

The `/bq` page exposes C16 Q34 test actions:

- OFF
- 1 percent
- 5 percent
- 25 percent
- 100 percent
- 5 percent pulse for 1 second, then OFF

The helper does not change PWM frequency or MODE2 output driver configuration.

## Quirks and Safety Notes

- PRE_SCALE may only be changed while MODE1 sleep is set. The helper intentionally does not change it.
- OE is active-low and can force all outputs to the configured disabled state.
- Power-on default has LED outputs off in the PCA9685 register model, but board-level gate drivers/MOSFETs must still be treated as unknown until traced.
- All 16 outputs share the same PWM frequency. Per-output duty cycle is controlled by ON/OFF count registers.
- Do not use PCA9685 writes as production discharge control until the `0x4F` conflict and every output-to-load mapping are resolved.
