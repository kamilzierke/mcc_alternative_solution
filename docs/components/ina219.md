# INA219 current and power monitor

Source datasheet: [TI INA219 current/power monitor](../datasheets/ti-ina219-current-power-monitor.pdf)

## Role in MCC Pro

The current native firmware treats INA219 devices as per-slot voltage/current monitors selected by HC4067 muxes:

- External path: U3 HC4067 enabled by IC25/PCF8574 P3 LOW, read through INA219 at `0x41`.
- Internal path: U2 BAT+ mux and U34 shunt mux enabled together by IC25/PCF8574 P4+P2 LOW, mask `0xEB`, read through INA219 at `0x4F`.

Current is derived from measured shunt voltage and the configured shunt value in firmware (`MCC_INA219_INTERNAL_SHUNT_MOHM`, `MCC_INA219_EXTERNAL_SHUNT_MOHM`).

## Pinout

| Pin | Function |
| --- | --- |
| IN+ | Positive shunt input |
| IN- | Negative shunt input; bus voltage is measured from this pin to GND |
| GND | Ground |
| VS | 3 V to 5.5 V supply |
| SCL | I2C/SMBus clock |
| SDA | I2C/SMBus data |
| A0 | Address select |
| A1 | Address select |

## Addressing

INA219 has 16 address combinations from A0/A1 tied to GND, VS, SDA or SCL.

Relevant current firmware addresses:

| Address | Path | Notes |
| --- | --- | --- |
| `0x41` | external INA219 | A1=GND, A0=VS according to the standard INA219 address table |
| `0x4F` | internal INA219 | A1=SCL, A0=SCL according to the standard INA219 address table |

Older notes mentioned `0x45`; the current model does not use it and treats U34 as a shunt HC4067 mux, not as an INA219.

## Registers Used

| Register | Name | Current firmware use |
| --- | --- | --- |
| `0x00` | Configuration | Written as `0x399F` before reads |
| `0x01` | Shunt voltage | Read and converted at 10 uV/LSB |
| `0x02` | Bus voltage | Read and converted at 4 mV/LSB after shifting status bits |
| `0x03` | Power | Read for raw diagnostics, not used for control |
| `0x04` | Current | Read for raw diagnostics, but firmware derives current from shunt mV |
| `0x05` | Calibration | Read for raw diagnostics; current firmware does not depend on INA current calibration |

## Quirks and Safety Notes

- INA219 bus voltage is measured at IN- relative to GND. If it differs from the physical battery terminal voltage, probe the INA219 input pins and mux outputs.
- Current and power registers remain zero unless calibration is programmed. The helper therefore derives current from shunt mV and configured shunt resistance.
- U2/U3 paths are not raw ADC paths. They must be read through INA219 after selecting the matching HC4067 channel.
- The internal path requires U2 and U34 on the same slot channel. Enabling U2 without U34 does not select the shunt path needed for current measurement.
- `0x4F` is also the address used by the experimental PCA9685/Q34 helper code. Treat this as an unresolved address conflict until hardware is verified.
