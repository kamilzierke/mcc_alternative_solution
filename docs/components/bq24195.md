# BQ24195 single-cell charger

Source datasheet: [TI bq24195/bq24195L charger](../datasheets/ti-bq24195-bq24195l-single-cell-charger.pdf)

## Role in MCC Pro

MCC Pro uses one BQ24195-class charger IC per slot. The devices share the repeated address `0x6B` and are isolated by two TCA9548A I2C switches:

| Slots | TCA | Channels | BQ address |
| --- | --- | --- | --- |
| C01..C08 | `0x70` | 0..7 | `0x6B` |
| C09..C16 | `0x71` | 0..7 | `0x6B` |

The native firmware queues all BQ reads and writes. HTTP handlers only enqueue work; the 250 ms main-loop interval performs one operation at a time.

## Registers Used

| Register | Name | Current firmware use |
| --- | --- | --- |
| `REG00` | Input source control | Read; writes `EN_HIZ` clear and `IINLIM` presets |
| `REG01` | Power-on configuration | Read; writes `CHG_CONFIG` and watchdog reset |
| `REG02` | Charge current control | Read; writes `ICHG` presets |
| `REG03` | Precharge/termination current | Read only in diagnostics |
| `REG04` | Charge voltage control | Read only in diagnostics |
| `REG05` | Charge termination/timer | Read; writes watchdog disable before charge on/off |
| `REG06` | Thermal regulation | Read only in diagnostics |
| `REG07` | Misc operation | Read only in diagnostics |
| `REG08` | System status | Read and decoded |
| `REG09` | Fault status | Read twice to observe latched/cleared behavior |
| `REG0A` | Vendor/part/revision | Read and decoded |

## Exposed Controls

| Control | Register effect |
| --- | --- |
| Charge ON | Clear `REG00[7] EN_HIZ`, disable watchdog in `REG05[5:4]`, set `REG01[5:4] CHG_CONFIG = 01` |
| Charge OFF | Disable watchdog in `REG05[5:4]`, set `REG01[5:4] CHG_CONFIG = 00` |
| Watchdog reset | Set `REG01[6] WDT_RESET = 1` |
| IIN 500/900/1500/3000 mA | Set `REG00[2:0] IINLIM` to codes `010`, `011`, `101`, `111` |
| ICHG 512/1024/2048/3008 mA | Set `REG02[7:2] ICHG` to codes `0`, `8`, `24`, `39` |

After every queued write action, the helper queues a follow-up read for the same slot.

## Quirks and Safety Notes

- Always select exactly one TCA channel before accessing `0x6B`.
- `REG00..REG07` are writable; `REG08..REG0A` are read-only status registers.
- The active BQ watchdog can revert host-written control state after timeout. The helper disables it before ON/OFF actions.
- `CE` is a hardware input as well as `CHG_CONFIG` being a register field. Charge behavior depends on both.
- Input current limit is the lower of the ILIM pin setting and the I2C `IINLIM` register setting.
- Full active charge/discharge automation is still out of scope until output mapping and a verified stop-all-outputs routine exist.
